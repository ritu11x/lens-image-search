About

How Lens works.

A hybrid semantic image search engine that understands both meaning and exact wording — built to run entirely on your own machine.

How it works

Every image is embedded with CLIP and automatically captioned with BLIP. Text queries are matched against a FAISS HNSW index for fast semantic retrieval, then reranked using a tunable blend of CLIP similarity and caption keyword overlap. Image queries reuse the same CLIP embedding space, enabling reverse image search.
